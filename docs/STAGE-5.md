# المرحلة 5 — الأزرار وسلامة المواقع والخريطة السعودية
تاريخ الإنجاز: 2026-09-14.

## المنجز
- أزيل اعتراض DarbakSaveButton وDarbakSavedButton لمستمعات MainActivity؛ أصبحت وظائف الحفظ والمحفظات الفعلية هي المرجع بدل لوحات قديمة مخفية داخل الأزرار.
- أضيف PointEditor موحد للاسم والنوع/الأيقونة والملاحظة، وأصبح زر حفظ الموقع الحالي والضغط المطول على الخريطة يستخدمانه.
- PlaceRepository لا يحذف المواقع بعد عدد ثابت، ويرفض الكتابة فوق مخزن JSON تالف؛ عمليات التعديل تستخدم commit وتبلغ عن فشل الكتابة بدل إظهار نجاح وهمي.
- التحقق من الإحداثيات قبل الحفظ.
- فُحص Artifact الخريطة السعودية الأصلية مباشرة: darbak-saudi.map، الحجم 189923374 بايت، SHA-256 409d7ecaf2d6c610921cfadd42855fbdd3ce63ae08a00ff94965b18bb25fdd1c.
- workflow Preserve Approved Saudi Map حفظ الملف نفسه في GitHub Release دائم باسم darbak-saudi-map-v1، run 34846638399 ناجح.
- RecommendedMapDownloader لم يعد ينزل gcc-states.map؛ أصبح ينزل فقط Release المعتمد ويتحقق من الحجم والبصمة وMapsforge قبل استبدال الخريطة، مع الاحتفاظ بالخريطة السابقة عند فشل التفعيل.

## ملاحظة التوقيع
المفتاح الثابت الجديد لا يطابق توقيع APK الاختبار القديم. لم يعثر على المفتاح الخاص القديم، كما أن DarbakMaps-Mishari-Source-Backup.rar يحتوي ملف خريطة فقط وليس مشروع Android/keystore. الانتقال إلى المفتاح الثابت سيكون خط أساس جديدًا يحتاج إزالة النسخة القديمة مرة واحدة إذا كانت هي المثبتة؛ لا يمكن جعل Android يقبل توقيعًا مختلفًا كترقية موضعية.

## الخطوة التالية
بوابة إصدار: رقم إصدار جديد، اختبارات lint/assemble، إنتاج APK ثابت التوقيع، التحقق من الشهادة والحزمة/SDK والحجم والبصمة، ثم نشر نفس الملف وتحديث manifest وDrive Latest. اختبار الشاشة الفعلي يبقى مرحلة قبول ميدانية منفصلة.
