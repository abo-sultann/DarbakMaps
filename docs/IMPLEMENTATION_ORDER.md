# DarbakMaps — IMPLEMENTATION ORDER

اعتماد المالك: 2026-09-14. هذه الوثيقة هي المرجع الأعلى عند تعارض تعليمات التنفيذ السابقة.

## ثوابت المشروع
- المستودع: `abo-sultann/DarbakMaps`.
- الجهاز: Allwinner T3، Android 7.1/API 25، 1024×600، RAM ~1GB.
- الحزمة التي يجب الحفاظ عليها: `com.abosultan.darbakmaps.debug`.
- عربية RTL، أوفلاين أولًا، هوية دربك، وعدم المساس بملف الخريطة أو بيانات المستخدم دون انتقال آمن.
- لا يوصف APK بأنه تحديث محافظ على البيانات قبل التحقق من شهادة النسخة المثبتة.
- لا يعتبر نجاح البناء وحده معيار إنجاز.

## المراجع التقنية المفتوحة — إلزامي قبل الميزات الكبيرة
- المرجع الرسمي: `docs/OPEN_SOURCE_REFERENCES.md`.
- المراجع المعتمدة: Organic Maps، Osmin، AAT Activity Tracker، GlanceMap، MBCompass، MGMapViewer، TrekMe، Cruiser GPS Navigation، Trailmap.
- الأولوية: Organic Maps للبحث/POI/Bookmarks/Tracks، Osmin للملاحة الأوفلاين On-road/Off-road وGPS/GPX، وAAT لـ Mapsforge/Offline POI/Track Recording/GPX/Hill Shading.
- قبل أي ميزة كبيرة: ابحث أولًا عن تنفيذ مشابه في المراجع، ادرس المعمارية والخوارزمية والحالات الحدية، ثم أعد تنفيذ الجزء المناسب فقط لدربك.
- لا ينسخ تطبيق كامل، ولا تعتمد مكتبة ثقيلة لمجرد وجودها في المرجع، ولا ينقل كود/asset فعلي قبل فحص الترخيص والـattribution.
- عند تعدد الحلول يختار أبسط وأخف حل متوافق مع Android 7.1 وT3 ويحافظ على الاستقرار والأداء.
- يجب ذكر المرجع الذي تمت مراجعته والقرار الناتج عنه في تقرير تنفيذ أي ميزة كبيرة.

## ترتيب التنفيذ الإلزامي
1. حماية البيانات وإصلاح دورة التسجيل والاستعادة.
2. تسجيل تلقائي دائم والاحتفاظ بآخر 1000 كم من المسافة المتصلة فعليًا.
3. البحث الأوفلاين والمعالم القريبة بفهرسة محلية قابلة للاستكمال.
4. حفظ المواقع بالأيقونات، قائمة القرب/الاتجاه، والتوجيه المباشر.
5. تكامل/أداء/توقيع/تحديث واختبار شاشة T3.

## TRACK — آخر 1000 كم
- التسجيل يبدأ تلقائيًا بعد منح صلاحية الموقع، ويستمر عند إغلاق Activity/إطفاء الشاشة ما دامت المنصة تسمح.
- الإقلاع يعيد تشغيل خدمة التسجيل دون فتح الواجهة تلقائيًا.
- الاحتفاظ حسب المسافة التراكمية المتصلة قبل تبسيط الرسم؛ الفجوات لا تحسب ولا توصل بصريًا.
- بعد تجاوز ~1001 كم يزال الأقدم تدريجيًا مع بقاء أحدث ~1000 كم، دون تصفير السجل.
- تثبيت النقطة الجديدة و`fsync` يسبق حذف القديم؛ أي تقليم يستخدم pending/backup وتعافي بعد انقطاع الطاقة.
- القفزات غير المعقولة وانحراف الوقوف تستبعد.
- العرض محدود النقاط والطبقات، بينما السجل/GPX المرجعي لا يعتمد على تبسيط العرض.
- حفظ نسخة GPX لا يوقف أو يمسح التسجيل التلقائي.
- pause/resume صريحان ومستمران، مع حالات يسجل/ينتظر GPS/متوقف/خطأ كتابة.
- Force Stop أو إطفاء الجهاز خارج ضمان التطبيق ويجب توثيق ذلك بوضوح.

## SEARCH — البحث والمعالم القريبة
- اسم كامل/جزئي، الأسماء العربية والبديلة، وتطبيع التشكيل والتطويل والألف دون تغيير نص العرض الأصلي.
- فئات: الكل، شعاب وأودية، جبال، معالم، قرى، مياه وآبار، خدمات، حسب ما هو موجود فعلًا في الخريطة.
- بحث حول السيارة أو معلم مختار ضمن 5/10/25/50/100 كم، وترتيب صلة أو أقرب.
- يفهرس POI والطرق/الخطوط/المساحات ذات المعنى، ويمنع التكرار.
- الفهرس محلي، متدرج، مرتبط بهوية ملف الخريطة ويستمر بعد إعادة التشغيل.
- لا تعرض “لا توجد نتائج” إذا كان الفهرس غير مكتمل، وتوضح حالات الاقتطاع/فشل أجزاء من الخريطة.
- العنصر غير المسمى يعرض نوعه دون اختراع اسم علم.

## SAVED — المواقع المحفوظة
- الحفظ من GPS أو نتيجة بحث أو نقطة خريطة.
- الأيقونات الأساسية الثابتة: سمان، مخيم، ماء، شجرة، صيد، علامة عامة؛ لا تعتمد على Emoji.
- الاسم والملاحظة اختياريان؛ الاسم الفارغ يولد وصفًا آليًا مميزًا بالتاريخ/الوقت.
- UUID/معرف ثابت، إحداثيات، نوع، تاريخ، اسم/ملاحظة.
- تبقى العلامات افتراضيًا على الخريطة ولا تتأثر بسجل 1000 كم.
- قائمة المحفوظات: فلاتر أيقونات، الأقرب أولًا، مسافة مباشرة، واتجاه نسبي للحركة؛ fallback جغرافي عند غياب heading موثوق.
- لا تعاد الصفوف تحت إصبع المستخدم، والضغط يوجه، والضغط المطول للتعديل/الحذف، مع تراجع عن الحذف.

## NAV — التوجيه والعودة
- التوجيه المباشر أوفلاين ويعرض الاسم/الاتجاه/المسافة/إلغاء، ويُوضح أنه خط مباشر لا طريق صالح مضمون.
- لا تعليمات انعطاف مصطنعة دون محرك طرق.
- فقد GPS يوقف الإرشاد المعتمد على موقع قديم.
- Backtrack يتبع المقاطع المتصلة فقط ولا يختار هدفًا افتراضيًا إذا لا يوجد مقطع صالح.
- بدء/إلغاء التوجيه لا يوقف التسجيل التلقائي.

## DATA — المراجعات الإلزامية
- LegacyMigration: فحص كامل مؤقت قبل التعديل، مساحة كافية، تطبيق قابل للتراجع، تنسيق مع كاتب المسار، وعدم استيراد runtime state قديم.
- BackgroundTrackService: عدم إسقاط writes المقبولة، Looper صحيح، استعادة FINALIZING، واحترام pause/run.
- RecommendedMapDownloader: backup لا يحذف بسبب ملف غير فارغ فقط؛ البديل يتحقق منه بالكامل قبل اعتماد التبديل.
- UI: حالة الحفظ والتسجيل تتحدث وهي مفتوحة.
- الرسم: سقف نقاط وطبقات فعلي.
- الإصدار: أسماء APK/manifest/Version/SHA/signature من ملف منشور واحد، وعدم نشر unsigned كتحديث.

## اختبارات القبول الأساسية
- مسار صناعي >1200 كم والتحقق من أحدث ~1000 كم، والفجوات وعدم حذف GPX اليدوي/المحفوظات.
- lifecycle: غلق Activity، شاشة مطفأة، reboot، GPS loss/recovery، process death أثناء write/trim/finalize، نقص المساحة.
- البحث بعينات مثبتة من ملف الخريطة لكل فئة المتاحة، حول السيارة ومعلم بعيد، aliases/partial/Arabic، dedupe، cap/resume/index change، قياس زمن/RAM.
- حفظ ≥3 مواقع سمان بلا أسماء + نوع آخر، reboot، filter/nearest، 359↔0، الوقوف/no compass/no GPS، توجيه للإحداثيات الصحيحة، عدم قفز الصفوف أثناء touch.
- تحديث النسخة المثبتة مع بقاء البيانات أو انتقال مختبر إذا اختلف التوقيع.

## معيار الإنجاز
لا تسمى النسخة نهائية إلا بعد إغلاق الاختبارات الممكنة وتوثيق ما لم يُختبر على شاشة السيارة. إن بقي اختبار T3 ميداني أو توقيع غير متحقق، الاسم الصحيح: **مرشح للاختبار الميداني**.
