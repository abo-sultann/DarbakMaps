# المراجع الهندسية — Darbak Maps 1.0

هذه المشاريع مراجع للأفكار والبنية وتجربة الاستخدام فقط. لا نسخ مباشر قبل مراجعة الترخيص والملفات التابعة.

- Organic Maps: البحث الأوفلاين، Bookmarks/Tracks، تجربة الخريطة، الاستيراد/التصدير. الكود Apache-2.0 مع متطلبات إسناد وبيانات بترخيص منفصل.
- Osmin: مرجع قوي للتوافق مع Android 7، Off-road، tracker، GPX، POI. ترخيص GPL-3.0؛ لذلك لا ينسخ كوده إلى Darbak دون قرار ترخيص صريح.
- AAT Activity Tracker: تتبع حي، GPX، خرائط أوفلاين، Offline POI، Mapsforge-compatible data؛ مرجع لتسجيل المسارات وإدارة الطبقات.
- بقية المراجع المعتمدة: GlanceMap، MBCompass، MGMapViewer، TrekMe، Cruiser GPS Navigation، Trailmap.

## قاعدة الاستفادة
نستخرج المشكلة والحل المعماري/UX أولًا، ثم ننفذ الحل بما يلائم Android 7.1 و1GB RAM وهوية دربك. ملف خريطة السعودية الحالي هو مصدر الخريطة المعتمد للمشروع.
