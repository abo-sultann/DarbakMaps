# Darbak Maps 1.0 — خطة التنفيذ الرسمية

## الهدف
تطبيق خرائط بر أوفلاين لشاشة السيارة: يعرف المستخدم أين هو، أين سبق أن مر، ما المواقع المهمة حوله، ويحفظ موقعًا بأيقونة ويعرف اتجاهه وبعده ويعود إليه بدون إنترنت.

## ثوابت التنفيذ
- لا نعيد استخدام واجهة 0.9.x أو مواردها البصرية.
- لا نغير ملف خريطة السعودية الحالي لمجرد إعادة البناء.
- لا نبدأ بتوجيه مدن ثقيل قبل ثبات وظائف البر الأساسية.
- لا ننقل كودًا من مشروع مرجعي قبل مراجعة الترخيص.
- يسمح بإعادة استخدام منطق داخلي موثوق من Darbak Maps القديم بعد مراجعته، مثل آلية التحديث الموقّع، دون نقل الهوية القديمة.

## الوظائف الأساسية للإصدار 1.0
- عرض `darbak-saudi.map` أوفلاين بأولوية صريحة.
- GPS وسهم السيارة وحالات القراءة المفقودة.
- حفظ موقع سريع بأيقونة نوعية، والاسم اختياري.
- مواقع محفوظة مرتبة بالأقرب مع المسافة والاتجاه والحذف الآمن.
- أثر تلقائي دائري حتى قرابة 1000 كم مع فصل المقاطع ومنع الجسور الوهمية.
- مسارات GPX محفوظة مستقلة لا تدخل في الحذف التلقائي.
- بحث أوفلاين في بيانات الخريطة والقريب والإحداثيات.
- توجيه بسيط للبر وBacktrack.
- تحديث موقّع من داخل التطبيق مع SHA-256 والتحقق من الحزمة والتوقيع.
- تشغيل تلقائي اختياري وتسجيل خلفي بعد الإقلاع.
- إعدادات/المزيد، تشخيص محلي مخفي، وحول بالتوقيع المعتمد.
- هوية دربك 2.0 في الرئيسية والنوافذ والحالات، مع اختفاء الأدوات بعد 6.5 ثوان.
- أيقونة تطبيق جديدة من لغة هوية 2.0، لا من bootstrap القديم.

## بوابة الإصدار الرسمي
1. clean build + unit tests + lint.
2. Visual QA على Android 7.1 / API 25 / 1GB / framebuffer 1024×600 الحقيقي.
3. مراجعة اللقطات بصريًا.
4. بناء Release بالمفتاح التاريخي المعتمد والتحقق من شهادة التوقيع.
5. SHA-256 وتحديث قناة التحديث الرسمية.
6. حفظ النسخة الرسمية كإصدار يمكن تحديثه لاحقًا من داخل التطبيق.

## التطوير بعد 1.0
أي ملاحظة ميدانية بعد الاعتماد تعامل كتحديث 1.0.x/1.1، وليس كذريعة لإرجاع النسخة إلى «تجريبية» أو إعادة بناء الأساس.
