# Darbak Maps 1.0 — خطة التنفيذ الرسمية

## الهدف
تطبيق خرائط بر أوفلاين لشاشة السيارة: يعرف المستخدم أين هو، أين سبق أن مر، ما المواقع المهمة حوله، ويحفظ موقعًا بأيقونة ويعرف اتجاهه وبعده ويعود إليه بدون إنترنت.

## ما لا نفعله
- لا نعيد استخدام واجهة 0.9.x.
- لا نغير ملف خريطة السعودية الحالي لمجرد إعادة البناء.
- لا نبدأ بتوجيه مدن ثقيل قبل ثبات وظائف البر الأساسية.
- لا ننقل كودًا من مشروع مرجعي قبل مراجعة الترخيص.

## المعمارية
1. `ui`: واجهة مستقلة لا تعرف تفاصيل Mapsforge/GPS/التخزين.
2. `core`: عقود MapEngine / LocationEngine / PlaceRepository / TrackRecorder / SearchEngine.
3. `data`: التخزين الآمن، الترحيل، النسخ الاحتياطي، إدارة ملف الخريطة.
4. `services`: تسجيل الأثر في الخلفية وحالات النظام.
5. `integration`: ربط المحرك بالواجهة دون تسريب تفاصيل التنفيذ.

## الوظائف الأساسية للإصدار الأول
- عرض الخريطة الحالية أوفلاين.
- GPS وسهم اتجاه السيارة وحالات القراءة القديمة/المفقودة.
- حفظ موقع سريع بأيقونة، والاسم والملاحظة اختياريان.
- مواقع محفوظة مرتبة بالأقرب مع المسافة وسهم الاتجاه.
- أثر تلقائي دائري حتى قرابة 1000 كم، ومسارات محفوظة لا تدخل في الحذف التلقائي.
- بحث أوفلاين في بيانات الخريطة + مواقع المستخدم.
- توجيه بسيط للبر: هدف + اتجاه + مسافة، بدون اشتراط Turn-by-Turn.
- إعدادات منظمة، تشخيص محلي مخفي، وحول موحد.

## ترتيب التنفيذ
0. تجميد القديم وحماية التاريخ والبيانات.
1. تأسيس مشروع نظيف + عقود المحرك + هوية 2.0.
2. بناء الشاشة الرئيسية الحقيقية على 1024×600 ببيانات تجريبية فقط للتصميم.
3. MapEngine وربط ملف الخريطة الحالي.
4. LocationEngine وسهم السيارة.
5. PlaceRepository وحفظ المواقع والأيقونات.
6. TrackRecorder والتسجيل الخلفي والحماية من الانقطاع.
7. SearchEngine والفهرس الأوفلاين.
8. التوجه للهدف والمسافة والاتجاه.
9. الإعدادات والتشخيص وحول والتحديث.
10. اختبارات الأعطال/التخزين/GPS/قتل العملية.
11. بوابة محاكي Android 7.1 بدقة 1024×600 ولقطات جميع الشاشات.
12. مرشح اختبار شاشة السيارة فقط بعد اجتياز البوابة.

## معيار النجاح
لا يعلن الإصدار مكتملًا حتى تعمل الخريطة وGPS والأثر والحفظ والبحث والتوجه وحماية البيانات، وتظهر الهوية الجديدة فعليًا على 1024×600، ثم يجتاز الاختبار الميداني.
