# Darbak Maps — Clean Rebuild 1.0

إعادة بناء نظيفة لتطبيق Darbak Maps لشاشة السيارة، بهوية دربك 2.0 فقط دون إعادة استخدام الواجهة القديمة.

## الثوابت
- Android 7.1 / API 25، شاشة 1024×600 أفقية، RTL، ذاكرة محدودة.
- `darbak-saudi.map` هو ملف الخريطة المعتمد وله أولوية صريحة.
- الهوية الرسمية: كحلي ليلي + أسطح زرقاء + إبراز سماوي؛ التصور الأخضر السابق ملغى.
- الوظائف الأساسية: خريطة أوفلاين، GPS، حفظ مواقع بأيقونات، بحث محلي، تسجيل مسار دائري حتى 1000 كم، GPX مستقل، Backtrack، تحديث موقّع من داخل التطبيق.
- لا تعتبر النسخة رسمية قبل اجتياز clean build + lint + Visual QA على Android 7.1 بدقة 1024×600، ثم إصدار موقّع بالمفتاح المعتمد.

راجع `docs/PROJECT_PLAN.md` و`docs/IDENTITY_CONTRACT.md` و`docs/REFERENCES.md`.

Official release baseline requested 2026-09-18.
