# DarbakMaps — دربك

تطبيق خرائط عربي خفيف لشاشات السيارات، مخصص للعمل في البر والمدن دون اتصال بالإنترنت ودون صور أقمار صناعية.

## الأساس المعتمد

- Android 7.0 (API 24) فما فوق.
- واجهة أفقية محسّنة أساسًا لدقة 1024×600.
- خرائط متجهية أوفلاين بصيغة Mapsforge `.map`.
- وضعان بصريان: البر والمدينة.
- GPS، سرعة المركبة، سهم اتجاه، حفظ المواقع، وتسجيل المسارات بصيغة GPX.
- بحث عربي أوفلاين في المدن والمعالم والخدمات والمواقع المحفوظة.
- تنزيل مباشر لحزمة الخليج الرسمية (السعودية ودول الخليج) مع استكمال التنزيل والتحقق من SHA-256.
- عرض المواقع المختارة والمسارات المحفوظة فوق الخريطة.
- رمز تفعيل لمرة واحدة مرتبط بالجهاز، دون تضمين سر التفعيل داخل APK.
- تحديث مباشر داخل التطبيق من خادم خاص، دون Google Play.
- هوية دربك الخضراء والذهبية المعتمدة.

## بناء نسخة التطوير

```bash
./gradlew :app:assembleDebug
```

ملف APK الناتج:

```text
app/build/outputs/apk/debug/app-debug.apk
```

نسخة `debug` تسمح بالدخول التطويري لتسهيل الاختبار. نسخة `release` لا تعمل دون ترخيص موقع من خادم التفعيل.

## حزمة الخريطة

من داخل التطبيق اختر **تنزيل خريطة الخليج الموصى بها**. حجمها نحو 307 م.ب، وتُنزّل من خادم Mapsforge الرسمي، ثم يتحقق التطبيق من سلامتها ويفعّلها تلقائيًا. يمكن إيقاف التنزيل واستكماله لاحقًا.

كما يمكن اختيار **إضافة خريطة من USB أو الذاكرة** لاستيراد أي ملف Mapsforge صالح بصيغة `.map`. بعد التنزيل أو الاستيراد تعمل الخريطة والبحث دون إنترنت.

## التفعيل والتحديث

تم فصل مفاتيح الأمان عن التطبيق. قبل إصدار النسخة التجارية يجب ضبط:

- `ACTIVATION_URL`: نقطة HTTPS لاستبدال الرمز الأحادي بترخيص موقع مرتبط برمز الجهاز.
- المفتاح العام للتحقق من الترخيص داخل `LicenseManager`، مع إبقاء المفتاح الخاص على الخادم فقط.
- `UPDATE_MANIFEST_URL`: ملف HTTPS يصف آخر نسخة ورابط APK وقيمة SHA-256.

نموذج ملف التحديث:

```json
{
  "versionCode": 2,
  "versionName": "0.2.0",
  "apkUrl": "https://updates.example.com/darbak-maps-0.2.0.apk",
  "sha256": "HEX_SHA256"
}
```

## حالة المشروع

الإصدار `0.2.0` هو أول إصدار اختبار ميداني: خريطة خليج جاهزة، بحث عربي أوفلاين، GPS، حفظ مواقع، تسجيل GPX، وعرض المسارات المحفوظة. المرحلة التالية تشمل خدمة تسجيل تستمر أثناء الانتقال بين التطبيقات، إدارة عدة حزم، ونظام التفعيل والتحديث التجاري.

جميع حقوق التطبيق محفوظة لأبوسلطان.
