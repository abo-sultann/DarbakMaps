# Darbak Maps — Clean Rebuild 1.0

هذا الفرع هو إعادة بناء نظيفة لتطبيق Darbak Maps لشاشة السيارة، وليس تطويرًا للواجهة القديمة.

## ثوابت المشروع
- Android 7.1 / API 25، شاشة 1024×600 أفقية، RTL، ذاكرة محدودة.
- ملف خريطة السعودية الحالي أصل ثابت؛ لا يتم استبداله ضمن إعادة البناء.
- هوية دربك الرسمية: مرجع الواجهات 2.0 (الكحلي الليلي/الأسطح الزرقاء/الإبراز السماوي). التصور الأخضر السابق ملغى.
- التصميم والمحرك منفصلان، ثم يتم الربط بعقود واضحة.
- لا يعتبر نجاح البناء قبولًا بصريًا أو ميدانيًا.
- لا APK للجهاز الحقيقي قبل بوابة محاكي 1024×600 ومراجعة اللقطات.
