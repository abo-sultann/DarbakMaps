# Darbak Maps — دربك

تطبيق خرائط شخصي خفيف لشاشة سيارة أبوسلطان، مخصص للبر والمدن والعمل دون اتصال بالإنترنت ودون صور أقمار صناعية.

> Darbak Maps مشروع خاص بالشاشة وليس مشروع نشر عام أو متجر تطبيقات.

## الأساس المعتمد

- Android 7.0 (API 24) فما فوق.
- واجهة أفقية محسّنة أساسًا لدقة 1024×600.
- خرائط متجهية أوفلاين بصيغة Mapsforge `.map`.
- خريطة Darbak الخاصة: **OSM حديث كأساس + بيانات المشاري الصحراوية كطبقة مكملة**.
- ثيم Darbak صحراوي مخصص بدل الثيمات العامة الجاهزة.
- GPS، سرعة المركبة، سهم اتجاه، حفظ المواقع، وتسجيل المسارات بصيغة GPX.
- بحث عربي أوفلاين في المدن والمعالم والخدمات والمواقع المحفوظة.
- عرض المواقع المختارة والمسارات المحفوظة فوق الخريطة.
- تحديث مباشر داخل التطبيق من المصدر الخاص بالمستخدم، دون Google Play.

## بناء نسخة التطوير

```bash
./gradlew :app:assembleDebug
```

ملف APK الناتج:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## حزمة الخريطة

الملف المستهدف النهائي:

```text
darbak-saudi.map
```

يتم إنتاجه من دمج منضبط للبيانات، وليس من تشغيل ملف Navitel داخل التطبيق:

1. بيانات OpenStreetMap حديثة للسعودية للطرق والمدن والخدمات.
2. بيانات خريطة المشاري للصحراء للمسارات البرية والأودية والفياض والقيعان والسباخ والجبال والآبار والمواقع البرية غير الموجودة في OSM.
3. إزالة التكرارات وإعطاء OSM الأولوية في الطرق والخدمات الحديثة، مع إبقاء تفاصيل المشاري الصحراوية المكملة.
4. تحويل الناتج إلى Mapsforge `.map`.
5. العرض بواسطة ثيم Darbak الموجود في:

```text
app/src/main/assets/renderthemes/darbak_desert.xml
```

تفاصيل خط إنتاج الخريطة وقواعد الدمج موثقة في:

```text
docs/MAP_DATA_PIPELINE.md
```

ما يزال التطبيق يدعم إضافة ملف Mapsforge صالح من USB أو الذاكرة للاختبار والرجوع إلى نسخة سابقة عند الحاجة.

## فلسفة العرض

الخريطة مصممة للقيادة والبر لا للاستعراض البصري:

- خلفية رملية هادئة.
- الطرق المعبدة واضحة لكن غير طاغية.
- الدروب البرية بارزة بدرجات مختلفة حسب جودة المسار.
- الأودية والشعاب الموسمية واضحة.
- أسماء المواقع البرية والجبال والآبار ذات أولوية أعلى من تفاصيل المباني.
- تقليل كثافة التفاصيل غير المهمة حفاظًا على أداء شاشة السيارة.

## حالة المشروع

المشروع في مرحلة تطوير الخريطة الخاصة. محرك Mapsforge، GPS، حفظ المواقع، تسجيل GPX والبحث الأوفلاين موجودة، وتم اعتماد ثيم Darbak الصحراوي كأساس العرض. المرحلة الحالية هي تجهيز حزمة `darbak-saudi.map` من OSM + بيانات المشاري واختبارها ميدانيًا على الشاشة.

جميع حقوق كود وتصميم تطبيق Darbak Maps محفوظة لأبوسلطان.
